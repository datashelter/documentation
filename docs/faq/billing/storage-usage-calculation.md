# How do you calculate storage usage?

We only track the overall storage usage, which means that you get the full benefits of our native compression, deduplication and retention policy features. We simply calculate the total size of the objects in your buckets.

To estimate the storage you may need before deployment, use the [Datashelter backup storage calculator](https://datashelter.tech/tools/backup-calculator). It lets you compare data volume, change rate, retention, compression, and cloud storage cost assumptions.
